1. Types of variables

  • bool Boolean: can only be 0 or 1
    • 0 = no, false, zero
    • 1 = yes, true, one
  • int Integer: whole numbers
    • Can have different "sizes" depending on memory allocated to them
  • str String: an ASCII character code
    • Example: D = 68 = 01000100
  • float Floating point: can also be in scientific notation
    • Example: 1.56e-17
    • Algorithms designed for int and float work differently
  • complex Complex Numbers: simply made of 2 floating point numbers

If you're ever unsure, ask python! 

type(variable)

1.1. bool

  • Booleans answer questions.
  • e.g. "is a the same value as b?"
  • x == y: are x and y equal?
  • x != y: are x and y unequal?
  • x < y: is x less than y?
  • x >= y: is x greater than or equal to y?
  • etc.

2.1. Modules let you import new capabilities

  • Python by itself doesn't know how to do much
  • People have written modules that make it better!
    • numpy for any numerical work
    • pandas for data processing
    • matplotlib for plotting
    • random for random numbers
  • Importing these capabilities can be confusing at first

    • import numpy gives you access to everything in numpy 

      import numpy
print(numpy.sqrt(100))

      Note that I still needed to tell python where sqrt is defined

    • from numpy import * imports everything and allows you to do: 

      from numpy import *
print(sqrt(100))

      This is dangerous because it can overwrite functions!

    • from numpy import sqrt if you only need one function

2.2. Recommended

  • import numpy as np gives numpy a 'nickname' 

    import numpy as np
print(np.sqrt(100))
  • Gives you access to numpy without always having to type it out
  • While not official, most people import numpy as np

2.4. Some other ways to grab stuff from arrays

x = [10, 20, 40, 80, 120]
print(x[1])          # the 2nd box, since counting starts at 0
print(x[1:3])        # includes the start, excludes the end
print(x[-1])         # 1 back from the end
print(x[-3:-1])      # can you predict the output?
print(x[0:len(x):2]) # can you predict the output?
print(x[::2])        # shortcut!

3.3. Repeating an operation on each element in an array

Position of a simple harmonic operator:

\begin{equation} \scriptstyle x(t) = x_0 \cos(2\pi t/T) \end{equation}

  1. Make an array of times from 0 to 7 seconds 

    t = np.linspace(0, 7, 1000)
  2. Now calculate the position.
    • If you feed an array into a numpy calculation, it does everything for you

    • This is called vectorized 

      x0 = 5
T = 3
x = x0 * np.cos(2 * np.pi * t / T)

    • Let's check 

      print("The first 10 elements, x = ", x[:10])

      The first 10 elements, x =  [5.         4.99946159 4.99784647 4.99515499 4.99138773 4.9865455
 4.98062935 4.97364054 4.96558059 4.95645123]

3.4. Functions are reusable code

Any time you want to repeat a task over and over, streamline!

  • Inputs and outputs are predefined (e.g., input time, output position)
    • e.g. np.cos() input is angle in radians, output is cosine

  • Simple function 

    def myfirstfunction(aword):
    print("The word is ", aword)
    • The indentation is important!
    • Try this!

  • Add 7 to an integer 

    def addSeven(number):
    return number+7

  • Try it! 

    newnumber = addSeven(4)
print(newnumber)

    11

  • Try with a numpy array 

    newarray = addSeven(np.array([1,2,3,4,10]))
print(newarray)

    [ 8  9 10 11 17]
